Client Report

Project “Tenses Off and Grounded”

Client: McMaster Mindfulness Club

Project Lead: That One Goose — Aloysius, Brian, Haoxuan, Jason

Purpose

Project Tenses Off and Grounded aims to modernize the McMaster Mindfulness Club’s digital presence by transitioning their static informational site into an interactive space that encourages student engagement through low-friction “small gestures.”

The club’s primary need is to support the McMaster community during digital fatigue while promoting mental well-being and combating mindfulness misinformation. The existing static website limits user interaction and community building.

TOG addresses this with four core features:

  • Authentication system
  • Guided breathing exercise module
  • Moderator-led daily engagement space (“The Daily Vibe”)
  • Modernized information hub

Client Feedback

The McMaster Mindfulness Club executive team responded positively to the concept, especially the focus on low-effort engagement and avoiding social media-style complexity.

Emoji Calendar Feedback: Suggested making mood visibility accessible to public users so students can feel less alone.

Breathing Module Feedback: Should be immediately accessible without login barriers, especially for digitally fatigued users.

The team agreed to prioritize frictionless access and distraction-free user flow.
